Local-first / inline project finder

WTFIS
HELP.

Where the fuck is your project? WTFIS searches your local folders with fuzzy matching, opens the right project, and lets your shell enter it without the directory archaeology.

wtfis / help 
$ wtfis --help
Where the fuck is your project?
A local-first, inline project finder for shells that should know where you work.

USAGE
  wtfis QUERY            Search immediately
  cdd QUERY              Short alias for wtfis

HELP CONTROLS
  Up / Down, Page Up / Page Down, Home / End to scroll
  q, Esc, or Enter to close

01Install

Install the command through Homebrew, then source the wrapper once so the parent shell can change directories after a selection.

brew tap prophesourvolodymyr/wtfis brew install wtfis
cat "$(brew --prefix)/share/wtfis/wtfis.zsh" >> ~/.zshrc source ~/.zshrc

For Bash, source wtfis.bash instead. Without shell integration, WTFIS can print paths but cannot change the parent shell directory.

02Usage

Run WTFIS with no query to open recent projects, or pass a project name, path, typo, or command preset directly.

wtfis # open inline search wtfis Mascotify # search immediately cdd Mascotify # short alias wtfis Mascotify /opencode # search, enter, and run a command

Launching wtfis with no query does not scan the filesystem. It opens immediately with up to five recently opened folders; scanning begins when you type the first search character.

03Direct commands

These commands act without opening the selector when the required shell or project state is available.

CommandAction
wtfis --setConfigure roots, depth, colors, and commands.
wtfis --upRecover a failed cd with a global home search.
wtfis --prevReturn to the previous directory. Requires shell integration.
wtfis --rootGo to a project root detected from .git or manifest files.
wtfis --lastReturn to the most recent project selected by WTFIS.
wtfis --wherePrint the detected project root without changing directory.
wtfis --homeGo directly to your home directory.
wtfis --recentOpen recent projects in the selector.
wtfis --helpShow the inline command guide.

04Search

Fuzzy by default.

Type a project name, path, or typo, then press Enter. Multiple words are required matches and can be typed in any order.

Safe matches.

Unique confident matches open immediately. Ambiguous matches stay in the selector so you can choose safely.

Local only.

Matching is local. Paths and project data never leave this machine. Semantic search is planned, but is not available yet.

Depth aware.

Search depth includes every layer up to the configured maximum. Shallower matches rank first.

05Slash commands

Type / in the selector to browse configured command presets. Commands can enter a project and run immediately, or be attached to a project for later use.

InputAction
/Browse configured command presets.
/opencodeEnter the project and run opencode.
/addAttach a preset or custom command to a project.
/exitLeave command mode.
/anythingRun any command after entering the project.

07Configuration

Reopen the settings screen at any time with wtfis --set. Configure search roots, hidden folders, exact depth, accent, marker, coffee reminders, and command presets from the inline settings UI.

roots = ["/Users/you/GSpace"] exact_depth = 3

exact_depth is a maximum directory depth. A value of 3 searches the root's first, second, and third layers.

08Shell integration

The wrapper captures the selected path and changes the parent shell directory after WTFIS exits. Homebrew installs the wrapper under share/wtfis and prints setup commands.

Zsh

cat "$(brew --prefix)/share/wtfis/wtfis.zsh" >> ~/.zshrc
source ~/.zshrc

Bash

cat "$(brew --prefix)/share/wtfis/wtfis.bash" >> ~/.bashrc
source ~/.bashrc

A failed cd path prints Try: wtfis --up for global recovery.
